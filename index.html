    ℹ️ Cos'è l'Entropia

    L'entropia di una password misura il numero di bit di informazione casuale contenuti. Una password con N bit di entropia ha 2^N possibili combinazioni.

    Formula: E = L × log₂(R)

    • E = Bit di entropia
    • L = Lunghezza password
    • R = Numero di caratteri possibili
    ⚡ Consiglio: Una password con 75+ bit è considerata forte. 100+ bit è eccellente.
    🎯 Linee Guida Sicurezza
    • ✅ Minimo 12 caratteri (16+ consigliato)
    • ✅ Mescola maiuscole, minuscole, numeri e simboli
    • ✅ Evita parole comuni o sequenze banali
    • ✅ Usa una password diversa per ogni account
    • ✅ Salva in un password manager affidabile
    • ❌ Non usare dati personali (nome, data nascita)
    • ❌ Non condividere la password
    💡 Nota: Le passphrases (sequenza di parole casuali) possono essere altrettanto sicure e più facili da ricordare.
